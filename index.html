Aim

To study and compare CPU scheduling algorithms using process arrival time and burst time, and to calculate completion time, turnaround time and waiting time.

Input

Process ID, arrival time, burst time and, for Round Robin, time quantum.

Output

Gantt chart, completion time, turnaround time, waiting time and average metrics.

Lab Procedure

  1. Add processes with their arrival and burst times.
  2. Choose FCFS, SJF, Round Robin or Multilevel Feedback Queue.
  3. Set a time quantum when required.
  4. Select Run Simulation and observe the highlighted Gantt segments.
  5. Record the process table and average waiting/turnaround times.
Round Robin:
1. Create ready queue and remaining burst copy.
2. Add processes at arrival time to the ready queue.
3. Remove first process; execute for min(quantum, remaining burst).
4. Record Gantt segment and advance clock.
5. Add newly arrived processes.
6. If process remains, add it to the queue; otherwise record completion time.
7. Repeat until queue and remaining processes are empty.

Turnaround Time = Completion Time - Arrival Time
Waiting Time = Turnaround Time - Burst Time
#include <stdio.h>

int main(void) {
    int n = 3, bt[] = {5, 3, 2}, wt[3], tat[3];
    wt[0] = 0;
    for (int i = 1; i < n; i++) {
        wt[i] = wt[i-1] + bt[i-1];
    }
    float sumWt = 0, sumTat = 0;
    printf("P  BT  WT  TAT\\n");
    for (int i = 0; i < n; i++) {
        tat[i] = bt[i] + wt[i];
        sumWt += wt[i];
        sumTat += tat[i];
        printf("P%d  %d   %d   %d\\n", i+1, bt[i], wt[i], tat[i]);
    }
    printf("Average WT = %.2f\\n", sumWt/n);
    printf("Average TAT = %.2f\\n", sumTat/n);
    return 0;
}
What is turnaround time?

Completion time minus arrival time.

What is waiting time?

Turnaround time minus burst time.

Why use a Gantt chart?

It gives a visual timeline of which process runs and for how long.

Does FCFS have convoy effect?

Yes. A long process can delay shorter processes that arrive later.
