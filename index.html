Aim

To study CPU scheduling algorithms and calculate completion, turnaround, waiting and response times.

Input

Process ID, arrival time, burst time, priority and time quantum.

Output

Animated Gantt chart, ready queue, process metrics and algorithm comparison.

Lab Procedure

  1. Add processes or load sample data.
  2. Select FCFS, SJF, SRTF, Priority, Round Robin or MLFQ.
  3. Set quantum and speed if required.
  4. Run or instantly complete the simulation.
  5. Compare metrics and record the final table.




What is turnaround time?
Completion time minus arrival time.
What is waiting time?
Turnaround time minus burst time.
What is response time?
First CPU start time minus arrival time.
How does priority scheduling work?
Lower priority numbers are served first in this simulator.
How does MLFQ work?
Processes move between three queues according to quantum use and queue priority.
